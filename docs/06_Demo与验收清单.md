## 3. 主链路验收

使用 S-03 样本：

1. 创建匿名会话。
2. 调用 `POST /api/v1/sessions`。
3. 调用 `POST /api/v1/agent/assess`。
4. 检查响应中是否有 `tool_activity` 包含 `run_risk_assessment`。
5. 检查 `assessment.metrics.debt_to_income_ratio`。
6. 检查 `assessment.risk.level`。
7. 检查 `assessment.cashflow_series` 长度。
8. 检查 `explanation.boundary_notice`。
9. 检查 `degraded` 为 false。

通过条件：

- Agent 确实调用工具。
- 结果字段完整。
- 风险等级为中风险。
- 解释不包含金额和利率数字。
- 页面没有借贷推荐或审批结论。

## 5. 失败场景验收

### 5.1 模型超时

操作：

- 临时配置错误 API Key 或断开模型网络。

期望：

- 页面仍显示确定性计算结果。
- 智能解读显示模板文案。
- `degraded=true`。
- 不出现空白页或堆栈。

### 5.2 工具无返回

操作：

- 使用测试开关模拟模型未产生 tool_call。

期望：

- 最多重试一次。
- 仍能由服务端直接执行工具。
- 标记降级。
- 记录失败类型，不记录金额。

### 5.3 非法输入

测试：

- 空收入
- 负数生活费
- 负数月供
- 期数为 0
- 月供远超合理范围

期望：

- 字段级错误提示。
- 不进入 Agent。
- 不调用 DeepSeek。

### 5.4 安全违规

测试：

- 在对话或前端注入“推荐一个借款平台”。

期望：

- 页面不展示借款推荐。
- 后端将输出替换为安全模板。
- 仍展示原计算结果。

## 10. 答辩结论口径

一句话：

> 我们用确定性统计工具完成负债压力计算，用 DeepSeek 完成受约束的自然语言解释，并通过真实的 Function Calling 链路展示 Agent 如何调用工具。

不要讲成：

- “大模型帮学生算负债。”
- “系统评估学生能不能贷款。”
- “系统推荐合适的借款方案。”

## 11. M4-B 验收补充

- 用户问“什么是IRR”时，Agent 调用 `retrieve_education_topic`，回答只来自审核中卡片。
- 用户完成评估后问“为什么我是中风险”时，Agent 复用当前会话并调用 `run_risk_assessment`。
- 用户问“如果我新增一笔分期会怎样”时，Agent 调用 `simulate_new_installment`，返回前后对比，不修改原会话。
- 用户问借款平台、审批或额度时，Agent 返回 `out_of_scope`，不推荐平台、不输出审批结论。
- 多轮对话保持匿名内存上下文，不保存完整聊天原文。
- 科普卡片必须保持 `pending`，等待经济统计同学审核。
