# StudentRiskGuard 双泳道模块开发任务卡

- 文档版本：MODULE-CARDS-2.0
- 使用方式：M0-M9 每个模块分别执行“计算机任务”和“统计任务”，联合验收门通过后才打钩。
- 提交门槛：M0-M7 全部通过 = 可提交 Agent；M8 只做打包冻结。

## 提交链路总览

```text
用户输入 -> 匿名会话 -> Agent 调用 run_risk_assessment(session_id)
-> 确定性计算工具 -> 结构化结果 -> DeepSeek 解释 -> 安全校验 -> 网页报告
```
