## 2. 冻结的字段和规则

### 2.1 输入

- `monthly_disposable_allowance`：扣除必要支出后的每月稳定可支配资金。
- `monthly_part_time_income`：每月兼职收入。
- `debts[].id`：会话内临时标识。
- `debts[].label`：仅用于展示的分期类型。
- `debts[].remaining_principal`：剩余本金，人民币元。
- `debts[].monthly_payment`：每月还款额，人民币元。
- `debts[].remaining_periods`：剩余期数，1-120。
- `debts[].nominal_apr`：名义年利率，小数，0-1。
- `forecast_months`：预测月份，默认 12，范围 1-36。

### 2.2 输出

- `metrics`：收入、月供、DTI、负债规模、笔数、结余和结余率。
- `irr_results`：逐笔 IRR、真实年化、状态和现金流假设。
- `risk`：0-100 分、四级风险、四维贡献和主要贡献项。
- `cashflow_series`：逐月收入、月供、结余和累计结余。
- `assumptions`：币种、收入固定假设和预测期。
- `warnings`：计算或数据异常。
- `model_version`、`parameter_version`：结果可追溯版本。

### 2.3 Agent 边界

- 大模型只接收 `session_id`。
- 工具在服务端读取匿名会话并执行确定性计算。
- 大模型只基于 `AssessmentResult` 生成解释。
- 模型不参与指标、IRR、评分和现金流计算。
- 原始财务明细不发送给大模型。
