## 1. 实现范围

- `metrics.py`：收入、债务月供、订阅月费、月度固定支出、DTI、剩余本金、结余和结余率。
- `irr.py`：以剩余本金为第 0 期现金流入、固定月供为后续现金流出，求解月度 IRR 并转换为有效年化。
- `scorecard.py`：读取并校验 `scorecard.json`，按冻结区间计算四维专家规则分数。
- `cashflow.py`：逐月计算有效债务月供、订阅费用、结余、累计结余和存款缓冲提示。
- `engine.py`：串联全部纯函数，输出经过 Pydantic 校验的 `AssessmentResult`。
- `synthetic.py`：加载五套冻结演示样本。
- `build_m2_research_report.py`：完成问卷分析、BNPL 外部对照、绘图和 docx 报告生成。

## 2. 冻结计算口径

### 2.1 DTI

```text
月度固定支出 = Σ债务月供 + Σ持续订阅月费
DTI = 月度固定支出 / (月度可支配资金 + 兼职收入)
```

订阅不属于债务本金，不计算 IRR，但会占用月度现金流，因此进入 DTI 和现金流推演。

### 2.2 IRR

```text
NPV(r) = -剩余本金 + Σ[月供 / (1+r)^月]
有效年化 = (1 + 月度IRR)^12 - 1
```

无法求解时返回 `unavailable`，不填充猜测值。

### 2.3 冻结评分卡

| 维度 | 最大分 | 规则 |
|---|---:|---|
| 月供负债收入比 | 35 | <30%得0；30%-39%得12；40%-49%得24；≥50%得35 |
| 多头分期笔数 | 15 | ≤2笔得0；3笔得6；4笔得10；≥5笔得15 |
| IRR真实年化成本 | 20 | <10%得0；10%-23.9%得6；24%-35.9%得12；≥36%得20 |
| 行为与韧性 | 30 | 以贷养贷10；严格逾期6；资金不足2/4/6；收入下降无法覆盖4；认知薄弱3；总分封顶30 |

风险档位：

- 0-24：低风险。
- 25-49：关注。
- 50-74：中风险。
- 75-100：高风险。

总分采用 half-up 四舍五入。每个维度输出原始值、得分、最大分、权重、贡献和主要贡献项。所有业务阈值和核心算法统一放在 `src/riskguard/core/`。

### 2.4 现金流

- 收入在预测期内保持不变。
- 债务月供仅在 `month_index <= remaining_periods` 时发生。
- 订阅费用在整个预测期发生。
- `cumulative_surplus` 从第 1 个月开始累计。
- 使用 `savings_balance` 判断现有存款能否覆盖预测期累计缺口。

## 3. 数据校准结论

### 3.1 问卷数据

- 原始答卷 214 份，注意力检查后有效样本 213 份。
- 明确有分期 152 人，表示不确定 36 人，合计 188 人。
- 按原始选项直接识别，3 笔及以上 108 人，占有笔数回答样本的 62.1%。
- 交接稿采用的 22.9% 是“5 笔及以上或不愿说明”的 43 人占 188 人的比例，属于高集中度保守口径，不能解释为精确的≥3笔比例。
- 严格逾期组 DTI 中位数 31.5%，从未逾期组 22.5%，Mann-Whitney 双边 p=0.050。
- DTI≥30% 的触发人数为 70/177，占 39.5%；DTI≥50% 为 30/177，占 16.9%。
- 金融认知量表 Cronbach α=0.7932，≤3 分的认知薄弱群体占 31.0%。

### 3.2 BNPL 数据

- 数据量 10,345 条，`default_flag` 阳性 4,040 条，总体违约率 39.05%。
- 违约组购买金额/月收入中位数 18.96%，未违约组 10.92%，双边 Mann-Whitney p<0.001。
- 学生子样本 2,531 条，违约与未违约组的该比例中位数没有显著差异，p=0.927。
- `debt_to_income_ratio` 实际为购买金额/月收入，不是产品定义的月供收入比。
- `bnpl_installments` 是单笔分期期数，不是同时负债笔数，不能直接替代问卷 Q2。

因此 BNPL 数据只用于外部方向性校验，不直接生成学生阈值。
