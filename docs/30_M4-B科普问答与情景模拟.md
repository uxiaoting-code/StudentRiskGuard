# M4-B 科普问答、情景模拟与统一对话

- 模块：M4-B（M4 增量）
- 日期：2026-11-06
- 依赖：M4-A 自然语言录入、M2 统计内核、M3 会话/工具、M4 AgentRunner
- 状态：技术实现通过；真实 DeepSeek 与教育卡片审核待完成

## 1. 统一入口

```http
POST /api/v1/agent/chat
```

支持以下确定性路由：

```text
assessment_intake
clarification
risk_explanation
education
scenario_simulation
out_of_scope
```

路由规则：

- 越界借贷意图优先阻断；
- 存在未完成草稿时优先追问；
- 存在会话时，情景问题进入模拟；
- 存在会话时，结果问题进入风险解释；
- 金融概念问题进入教育卡片；
- 无会话情景问题提示先完成自评。

## 2. 工具

```text
run_risk_assessment(session_id)
retrieve_education_topic(topic_id)
simulate_new_installment(session_id, scenario_id)
```

情景模拟的明细保存在进程内存的 ScenarioStore 中，模型只能拿到 scenario_id。模拟服务复制当前 AssessmentRequest，追加临时 Debt，再调用同一个 M2 AssessmentService，不修改原会话。

## 3. 科普内容

`src/riskguard/data/education_cards.json` 当前包含 10 个主题：

- 低月供不等于低总成本
- IRR和真实年化成本
- 分期期限与现金流
- 多笔小额负债叠加
- 订阅和自动续费
- 存款缓冲
- 兼职收入波动
- 以贷养贷风险
- 理性消费和预算
- 与家人或学校支持资源沟通

所有卡片当前为 `review_status=pending`。只有经济统计同学审核后才能改为 `approved`，页面必须显示待审核标记。

## 4. 上下文

`ConversationStore` 保存：

- conversation_id
- session_id
- current_intent
- last_topic
- last_assessment_id
- last_tool
- last_answer_type
- clarification_turns
- pending_question
- created_at / expires_at

只存在进程内存，TTL 30 分钟，不保存完整聊天原文。

## 5. 隐私

- 自然语言只发送给抽取、科普或情景抽取模型；
- 报告模型只接收 AssessmentResult；
- 原始文本不写入 ConversationStore、DraftStore、日志、数据库或 localStorage；
- 工具参数只包含 session_id、topic_id 或 scenario_id；
- 公开演示前需要确认新的自然语言抽取隐私边界。

## 6. 最小安全校验
