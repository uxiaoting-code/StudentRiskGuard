## 1. 页面入口

```text
app.py
-> src/riskguard/ui/streamlit_app.py
```

页面包含：

- 智能对话自检；
- 结构化表单自检；
- 五套合成演示样本；
- 风险报告；
- 四维贡献；
- 逐笔 IRR；
- 现金流图；
- Explanation 展示；
- Agent 工具轨迹；
- 科普回答；
- 新增分期情景模拟；
- 固定隐私与边界声明。

## 2. API 客户端

```text
src/riskguard/ui/api_client.py
```

使用 `httpx` 调用 FastAPI：

```text
RISKGUARD_API_URL
默认 http://127.0.0.1:8000
```

禁止在 Streamlit 中重新计算风险分、IRR 或现金流，所有数值来自后端。

## 3. 临时状态

```text
src/riskguard/ui/state.py
```

只使用 Streamlit `session_state` 保存当前页面状态：

- conversation_id；
- session_id；
- 最近一次响应；
- 预览；
- 工具轨迹；
- 错误提示。

不使用数据库、localStorage、CSV 或文件持久化个人明细。

## 4. 本地运行

后端：

```powershell
.\.venv\Scripts\python.exe -m uvicorn riskguard.api.main:app --app-dir src --reload
```

前端：

```powershell
streamlit run app.py
```

当前 `.venv` 需要安装 Streamlit 后才能运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```
