# M5.5 账号与认证方案

- 模块：M5.5
- 日期：2026-11-09
- 依赖：M5 页面闭环
- 状态：代码与自动化验收完成，待真实公网手工复核

## 1. 产品形态

保留两种模式：

- 访客模式：无需注册、无需登录，直接试用全部金融教育和风险自查功能；
- 账号模式：注册、登录、查看当前用户、退出登录。

登录不是风险评估、科普问答或情景模拟的前置条件。

## 2. 后端接口

```http
POST /api/v1/auth/register
POST /api/v1/auth/login
POST /api/v1/auth/logout
GET  /api/v1/auth/me
```

认证使用 Bearer Token：

```http
Authorization: Bearer <token>
```

## 3. 数据边界

SQLite 认证数据库只允许保存：

users
- id
- username
- password_hash
- created_at
- consent_version

auth_sessions
- id
- user_id
- token_hash
- created_at
- expires_at

禁止保存：

- 收入
- 债务
- 月供
- 利率
- 订阅
- 存款
- AssessmentRequest
- AssessmentResult
- Explanation
- 原始聊天文本
- API Key

财务明细仍然只保存在进程内存中。

## 4. 安全方案

- 密码使用 `hashlib.scrypt` 和随机 salt 哈希；
- 不保存明文密码；
- 登录 token 使用 `secrets.token_urlsafe`；
- 数据库只保存 token 的 SHA-256 哈希；
- token 默认 24 小时过期；
- 退出登录删除认证会话；
- 认证错误不泄露用户是否存在；
- 密码、salt 和 token 不写入日志；
- token 只放在 Streamlit `session_state`，不写入 localStorage。

## 5. 环境变量

```text
AUTH_DB_PATH
AUTH_TOKEN_TTL_MINUTES
```

默认：

```text
AUTH_DB_PATH=data/auth.db
AUTH_TOKEN_TTL_MINUTES=1440
```

`*.db` 已在 `.gitignore` 中排除，认证数据库不得提交。

## 6. 页面交互

侧边栏提供：

- 访客提示；
- 登录/注册表单；
- 注册规则说明和字段提示；
- 提交前用户名、密码和确认密码校验；
- 当前用户名；
- 退出登录。

注册规则：

- 用户名长度为 3～32 位，只能使用英文字母、数字和下划线；
- 用户名不区分大小写且不能重复；
- 密码长度为 8～128 位；
- 注册时两次输入的密码必须一致；
- 当前不收集邮箱、手机号、真实姓名、学校或学号，也不支持邮箱找回密码。

前端校验失败时直接显示中文提示，不调用后端；后端 Pydantic 校验和 AuthService 仍是最终权威。认证接口返回的 422 原始字段路径不会展示给用户。

访客和登录用户使用同一套：

- 智能对话自检；
- 结构化表单；
- 风险报告；
- 科普问答；
- 情景模拟；
- 工具轨迹。

## 9. 与 M5.6 对话记忆的边界

- M5.6 的 ChatMemoryStore 是独立的进程内存组件，不写入认证 SQLite 数据库；
- 认证数据库继续只保存 users 和 auth_sessions；
- 登录、注册、退出和访客模式不受追问轮数影响；
- 认证 token 不写入 ChatMemoryStore；
- 删除 Agent conversation 不删除认证账号；退出登录也不自动删除匿名评估会话，用户可通过重新开始或清空界面显式清理；
- 登录用户和访客都必须遵守相同的原始文本、完整历史和报告模型边界。
## 10. M5.5.1 注册规则与错误提示

- 注册模式显示用户名、密码、确认密码和唯一性规则；
- 登录模式说明用户名不区分大小写，当前不支持邮箱找回密码；
- 用户名输入框提示合法格式和示例；
- 密码输入框提示 8～128 位长度要求；
- 提交前由共享校验模块检查用户名、密码和确认密码；
- 登录和注册均不发送非法格式请求；
- UI API 客户端将 422 字段错误转换为中文提示；
- 登录失败统一提示“用户名或密码错误，请检查后重试”，不泄露账号是否存在；
- 用户可见文本不包含 Pydantic 字段路径、JSON key 或英文异常；
- 新增 `tests/test_auth_validation.py` 和 `tests/test_ui_auth_form.py`；
- 后端认证数据库结构、密码哈希和 token 语义未改变。

Render 免费演示实例使用临时 `/tmp` 认证数据库，服务重启或重新部署后账号可能丢失；访客模式不受影响。
