# M5.5 账号与认证方案

- 模块：M5.5
- 日期：2026-11-08
- 依赖：M5 页面闭环
- 状态：代码实现完成，待手工界面和经济统计隐私复核

## 1. 产品形态

保留两种模式：

- 访客模式：无需注册、无需登录，直接试用全部金融教育和风险自查功能；
- 账号模式：注册、登录、查看当前用户、退出登录。

登录不是风险评估、科普问答或情景模拟的前置条件。

## 2. 后端接口

```http
POST /api/v1/auth/register
POST /api/v1/auth/login
POST /api/v1/auth/logout
GET  /api/v1/auth/me
```

认证使用 Bearer Token：

```http
Authorization: Bearer <token>
```

## 3. 数据边界

SQLite 认证数据库只允许保存：

users
- id
- username
- password_hash
- created_at
- consent_version

auth_sessions
- id
- user_id
- token_hash
- created_at
- expires_at

禁止保存：

- 收入
- 债务
- 月供
- 利率
- 订阅
- 存款
- AssessmentRequest
- AssessmentResult
- Explanation
- 原始聊天文本
- API Key

财务明细仍然只保存在进程内存中。

## 4. 安全方案

- 密码使用 `hashlib.scrypt` 和随机 salt 哈希；
- 不保存明文密码；
- 登录 token 使用 `secrets.token_urlsafe`；
- 数据库只保存 token 的 SHA-256 哈希；
- token 默认 24 小时过期；
- 退出登录删除认证会话；
- 认证错误不泄露用户是否存在；
- 密码、salt 和 token 不写入日志；
- token 只放在 Streamlit `session_state`，不写入 localStorage。

## 5. 环境变量

```text
AUTH_DB_PATH
AUTH_TOKEN_TTL_MINUTES
```

默认：

```text
AUTH_DB_PATH=data/auth.db
AUTH_TOKEN_TTL_MINUTES=1440
```

`*.db` 已在 `.gitignore` 中排除，认证数据库不得提交。
