# M5.8 前端对话体验优化

- 模块：M5.8
- 状态：代码完成，待真实浏览器手工验收
- 范围：只优化 Streamlit 展示层和交互状态，不修改 M2 公式、认证数据库和后端工具边界

## 1. 页面形态

页面调整为：

```text
产品介绍
-> 类大模型对话气泡
-> 一问一答录入
-> 结构化确认
-> 风险报告
-> 报告后继续追问
```

使用 Streamlit 原生 `st.chat_message`、`st.chat_input`、`st.status` 和 `st.session_state`，不引入新的前端框架。

## 2. 左侧栏

默认只保留用户和当前自检相关信息：

- 账号、登录/注册、访客状态；
- 是否已经开始对话；
- 清空并重新开始；
- 对话信息；
- 开发者信息折叠区。

API 地址、版本号和技术说明不再默认占据主要视觉位置。

## 3. 对话与追问

- 用户和助手使用聊天气泡展示；
- 助手头像使用盾牌图标；
- 每个追问只显示一个问题；
- 追问包含当前债务标签；
- 报告生成后显示“继续追问这份报告”；
- 快捷问题可以继续问 Agent，而不是只让用户线下思考；
- 报告后继续使用同一个 conversation_id。

## 4. 风险报告

- 风险等级使用颜色卡片；
- 风险维度显示中文标签；
- 逐笔 IRR 使用债务标签或“第 N 笔分期”作为显示名称；
- 现金流和风险报告仍由现有工具结果渲染；
- 所有数值仍来自确定性 M2 结果。

维度映射：

```text
debt_to_income -> 月供收入比
debt_stack -> 多笔负债叠加
real_cost -> 真实资金成本
behavior_resilience -> 行为与韧性
```

## 5. 加载状态

确认并生成报告时：

- 使用 `st.status` 展示当前阶段；
- 显示明显的右下角加载浮层；
- 请求完成后状态消失；
- 保持确认按钮防重复提交逻辑。

## 6. 颜色主题

新增 Streamlit 主题配置文件：

```text
.streamlit/config.toml
```

使用深蓝、青绿、浅灰白和风险等级配色，避免影响数值和数据结构。

## 7. 隐私边界

- 页面不写 localStorage；
- 不把完整聊天历史发送给 LLM；
- 不把原始文本发送给报告模型；
- 债务标签映射只保存在页面 session_state；
- 删除会话时继续清理后端内存状态。
