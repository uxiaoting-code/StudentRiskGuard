# M6 安全、隐私与降级验收

- 模块：M6
- 任务：T22 安全校验、T23 隐私与日志
- 状态：代码完成，待真实浏览器和安全人工复核
- 依赖：M5 页面闭环、M5.5 认证、M5.6 有界追问、M5.7 向导、M5.8 对话体验
- 范围：只做安全、隐私、降级和验收，不实现 M7 公网部署，不修改 M2 公式

## 1. 安全边界

M6 必须保证：

- 不推荐借款平台、贷款平台、借贷产品、分期或投资产品；
- 不判断贷款审批、通过率、授信额度或放款结果；
- 不承诺收益、保本、稳赚或解决债务；
- 不提供以贷养贷、借新还旧方案；
- 不诱导用户提供身份证、学号、银行卡、征信报告或真实账单；
- 不展示模型思维链；
- 所有报告显示固定免责声明；
- 违规输出必须替换为安全模板或 out_of_scope。

## 2. 解释安全

解释输出必须：

- 符合 Explanation Schema；
- dimension_id 来自 AssessmentResult.risk.dimensions；
- boundary_notice 逐字匹配固定声明；
- 不新增阿拉伯数字；
- 不重新计算指标、IRR、评分或现金流；
- 通过确定性 safety 检查后才能展示。

后端使用确定性 grounding：模型只选择合法风险维度，后端丢弃自由文本并重新组装 Explanation。任何异常都回退模板解释。

## 3. 降级策略

已覆盖：

- 模型超时；
- 模型网络错误；
- 空 choices；
- 非法 JSON；
- 非法 Explanation Schema；
- 无 tool_call；
- tool_call 切换 session；
- 工具执行异常；
- 非法 dimension_id；
- 未授权数字；
- 违规解释内容。

降级时仍展示：

- AssessmentResult；
- 模板 Explanation；
- degraded 状态；
- 工具轨迹；
- 固定免责声明。

## 4. 隐私

- 报告模型只接收 AssessmentResult；
- 当前轮必要文本只发送给抽取、科普或情景模型；
- 不发送完整聊天历史或完整财务档案；
- 不把原始文本写入日志、数据库、CSV、文件或 localStorage；
- ChatMemoryStore 仅进程内存，默认 TTL 1800 秒、最多 8 条；
- 删除 conversation 时级联清理相关内存状态；
- 认证 SQLite 只保存 users 和 auth_sessions；
- 认证数据库不保存收入、债务、订阅、评估结果或聊天文本。
