## 2. 计算口径

- 名义年利率使用小数存储，例如12%为0.12。
- 月利率为 `nominal_apr / 12`。
- 等额本息月供：
  `PMT = P*r*(1+r)^n / ((1+r)^n-1)`。
- 零利率时 `PMT = P/n`。
- 合同剩余还款总额默认为 `PMT*n`。
- 最后一期不同时，使用 `PMT*(n-1)+final_payment`。
- 资金成本为合同总还款减剩余本金。
- 一致性容差为 `max(1元, 理论月供的0.5%)`。
- 明显冲突时要求用户确认“以实际月供为准”或“按利率重新计算月供”。

## 3. 隐私与安全

- 所有最终金融数字由Python计算。
- LLM只负责语义识别、同义词、歧义和解释选择。
- 报告解释模型不接收原始聊天文本。
- 财务数据仍只保存在进程内存。
- 认证数据库不保存债务、评估结果或聊天原文。
